# 🎮 Respawn Store

Respawn Store es una tienda web de videojuegos desarrollada como trabajo práctico para la materia **Aplicaciones Web Cliente**.

La aplicación permite explorar un catálogo de juegos, visualizar el detalle de cada producto, agregar títulos al carrito de compras y administrar una lista de favoritos. Toda la información se obtiene desde un archivo JSON y los datos del usuario se almacenan localmente mediante **LocalStorage**, permitiendo conservar el carrito y los favoritos entre sesiones.

El diseño está inspirado en la estética gamer, utilizando una paleta de colores neón, tipografía moderna y una interfaz responsive adaptable a distintos dispositivos.

---

## Funcionalidades

* Visualización del catálogo de videojuegos.
* Página de detalle para cada juego.
* Agregar y eliminar juegos de favoritos.
* Carrito de compras con control de cantidades.
* Persistencia de datos mediante LocalStorage.
* Carga dinámica de información utilizando Fetch API.
* Diseño responsive para computadoras, tablets y dispositivos móviles.
