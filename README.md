# Respawn Store

Respawn Store es una landing page enfocada en la venta de videojuegos, licencias de software y contenido digital. El proyecto fue desarrollado utilizando HTML y CSS, aplicando diseño responsive y una estética gamer inspirada en tonos neón y pixel art.

---

## Tecnologías utilizadas

- HTML
- CSS
- Flexbox
- Media Queries
- Clamp()
